VK Music in Discord / ВК Музыка в Дискорде (MUFORDS) Версия 1.0

### Всем привет!! Представляю софт для показа музыки из ВК Музыки в Дискорд.
Как работает? Расширение ищет музыку в ВК Музыке, которая играет в данный момент и посылает в обычный exe файл данные о музыке и отображает это в Дискорд.

Вообщем обычным пользователям это не прям важно знать, но если есть какие то вопросы по данному софту пишите в телеграм @FAC0S
буду рад услышать, что можно улучшить и тп.

**ПОШАГАВАЯ ИНСТРУКЦИЯ ПО УСТАНОВКЕ** !!! ↓↓↓
